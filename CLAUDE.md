## Change log rule (required)

After every change to this project (code, styles, config, assets, installed tools), add an entry at the top of `docs/BADLAV-HINGLISH.md` in the same turn. Write it in simple Hinglish (Roman script) for a non-technical owner. Each entry covers: Kya badla, Kyun, Kaun si files, Kaise check karein, Dhyan dene wali baat. Also keep the English `docs/CHANGELOG.md` updated.
